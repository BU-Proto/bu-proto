Proto logo pack
===============

Mark: the Proto mark, traced 1:1 from the original 2048 px artwork (unchanged).
Wordmark: "Proto" in Satoshi Bold, default spacing, the same typeface and
weight as the ScottyLabs wordmark. Letters are converted to outlines, so
nothing needs to be installed to use these files.

Layouts
  01-horizontal          mark + "Proto", centred on one line
  02-vertical            mark centred above "Proto"
  03-horizontal-large    big mark with "Proto" sitting on its baseline
                         (ScottyLabs proportions)
  04-wordmark            "Proto" text only
  05-mark                mark only, now as vector (SVG/PDF)
  06-social-square       1080 and 2048 px squares (PNG + JPG) for avatars/posts

Formats in each layout folder
  svg/  vector, transparent background, ink = black / white / blue
  pdf/  vector for print and merch, same three inks
  png/  3000 px: transparent versions + black-on-white, white-on-black,
        white-on-blue, blue-on-white

Colours
  Black  #000000
  White  #FFFFFF
  Blue   #1A2FFB  (sampled from the original blue logo)

Typesetting the name elsewhere (site, slides): Satoshi Bold, letter-spacing 0.
Satoshi is free from Fontshare (ITF Free Font License); a copy is in your
Downloads as Satoshi_Complete.zip.
